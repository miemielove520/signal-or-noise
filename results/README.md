# Results

| Path | What it is |
|---|---|
| [`REPORT.md`](REPORT.md) / `REPORT.pdf` | The statistical post-mortem. The PDF is typeset from the Markdown by `scripts/build_report_pdf.py`. |
| [`summary.json`](summary.json) | Every number quoted in the report and README. Regenerated byte for byte by `python research/forward_test.py`. Returns are fractions (0.01 = 1 %). |
| `figures/` | Every figure in the report, regenerated by the same script. |
| `data/` | The inputs, exported from the running pipeline by `scripts/export_results.py`. |

## Data dictionary (`data/`)

| File | Rows | One row is | Key columns |
|---|---|---|---|
| `walk_forward_signals.csv` | 6,219 | one (signal date, stock, horizon profile) in the v2 walk-forward backtest. The three profiles of a (date, stock) share one outcome. | `high_probability_score`, `calibrated_win_probability` (the model's label), `forward_return_5d/20d/60d` |
| `backtest_portfolio_vs_benchmark.csv` | 1,688 | one day of one backtest portfolio variant vs SPY or QQQ | `portfolio_daily_return`, `benchmark_daily_return`, `excess_daily_return` |
| `backtest_probability_calibration.csv` | 6 | one probability bucket of the backtest's own calibration table | estimated vs actual 20-day win rate |
| `paper_equity_history.csv` | 53 | one successful paper-portfolio valuation run (through the 2026-09-26 run) | `executed_at` (UTC), `date` (run date), `equity` (USD), `benchmark_close` (QQQ) |
| `paper_orders.csv` | 118 | one simulated order | `as_of_date` (run date), `action`, `quantity`, `close_price`, `fill_price`, `notional` (USD), `total_transaction_cost` (USD) |
| `forward_window_prices.csv` | 61 | one trading day, Jul – Sep 2026 | adjusted close of each universe stock, QQQ and SPY |
| `qqq_history.csv` | 434 | one trading day since Jan 2025 | QQQ adjusted close |
| `universe.csv` | 150 | one listed candidate ticker | `ticker` |

**Run dates and price dates differ.** A run before the market close, or on a non-trading day, marks the portfolio at the previous session's close. The analysis maps each run to the close it used with `stock_selector.paper_tracker.price_dates_for_runs`.

**Data sources.** Market prices (`forward_window_prices.csv`, `qqq_history.csv`) were downloaded from Yahoo Finance through yfinance for research reproduction. They are third-party data and are not covered by this repository's MIT license. The other files are outputs of this project's own code.
